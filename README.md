# AI 자막 수집기 받기

국회 인터넷의사중계·유튜브 등 영상 화면에 나오는 자막을 모아 txt로 저장하거나 복사해 주는 **윈도우 프로그램**입니다.
설치하지 않고, 압축만 풀면 바로 실행됩니다.

## ⬇ 받기 (누르면 바로 받아집니다)

### ▶ [프로그램 받기 (최신판, zip)](https://github.com/roba97-web/subtitle-download/releases/latest/download/AI-Subtitle-Portable.zip)

### ▶ [사용법 PPT 받기](https://github.com/roba97-web/subtitle-download/releases/latest/download/AI-Subtitle-Guide.pptx)

> 두 링크는 늘 **가장 최신 버전**을 받습니다. 버전이 바뀌어도 링크는 그대로입니다.

## 실행 방법

1. 위의 **[프로그램 받기]** 를 눌러 zip 파일을 받습니다.
2. 받은 zip 파일을 **마우스 오른쪽 버튼**으로 누르고 **[모두 압축 풀기]** 를 누릅니다.
3. 풀린 **AI-Subtitle** 폴더 안의 **NASubtitle.exe** 를 더블클릭합니다.
4. 파란색 **"Windows의 PC 보호"** 창이 뜨면 **[추가 정보]** → **[실행]** 을 누릅니다.
5. (자주 쓰면) NASubtitle.exe 를 마우스 오른쪽 버튼 → **[보내기]** → **[바탕 화면에 바로 가기 만들기]**

## 알아두세요

- zip을 풀지 않고 안에서 바로 실행하면 안 됩니다. 꼭 **압축을 푼 뒤** 실행하세요.
- 모은 기록은 같은 폴더의 **data** 폴더에 저장됩니다. 폴더를 지우면 기록도 지워집니다.
- **업데이트**: 새 zip을 받아 풀고, 나온 NASubtitle.exe 를 쓰던 폴더에 덮어쓰면 기록이 그대로 남습니다.
- 회사 VDI처럼 재부팅하면 초기화되는 PC는 켤 때마다 다시 받아서 압축을 풀어야 합니다.
- 자세한 사용법은 **사용법 PPT** 를 보세요.
- 예전 버전은 [버전별 목록](https://github.com/roba97-web/subtitle-download/releases)에서 받을 수 있습니다.

※ 국회 영상·자막은 국회법 제149조에 따라 상업적 목적으로 사용할 수 없습니다.
